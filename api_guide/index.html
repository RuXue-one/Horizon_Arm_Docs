API密钥获取指南¶

概述¶

Horizon Arm软件不包含具身智能部分的第三方AI服务API密钥。为了使用具身智能功能，您需要自行注册并获取以下平台的API密钥：

  • 阿里云通义千问（Alibaba Qwen）
  • DeepSeek深度求索

本指南将详细说明如何在这两个平台上注册账号并获取API密钥。

为什么需要自行获取API密钥？¶

隐私与安全： - 保护您的使用数据和隐私 - 避免共享密钥带来的安全风险 - 确保服务稳定性和可用性

成本控制： - 您可以根据自己的需求选择付费方案 - 透明的用量统计和费用管理 - 避免额外的服务费用

服务质量： - 独立的API配额和速率限制 - 更好的服务响应速度 - 完全控制服务使用权限

阿里云通义千问 API 获取教程¶

1. 注册阿里云账号¶

访问官网 - 打开浏览器，访问：https://www.aliyun.com - 点击右上角"免费注册"按钮

注册流程 1. 选择注册方式： - 手机号注册（推荐） - 邮箱注册

  1. 填写注册信息：
  2. 输入手机号/邮箱
  3. 设置登录密码
  4. 输入短信验证码

  5. 勾选同意用户协议

  6. 完成注册：

  7. 点击"注册"按钮
  8. 完成实名认证（需要身份证信息）

💡 提示：阿里云要求实名认证才能使用API服务，请准备好身份证信息。

2. 开通通义千问服务¶

进入控制台 - 登录后，访问：https://dashscope.aliyun.com - 这是阿里云的模型服务平台（灵积平台）

开通服务 1. 首次访问会提示开通服务 2. 点击"立即开通"按钮 3. 阅读并同意服务协议 4. 选择付费方式： - 按量付费（推荐新手）：根据实际使用量计费 - 资源包：预付费套餐，适合大量使用

💰 费用参考： - 新用户通常有免费额度（具体以官网为准） - 通义千问系列模型按Token计费 - qwen-turbo: ¥0.002元/千tokens（输入） - qwen-plus: ¥0.004元/千tokens（输入） - qwen-max: ¥0.02元/千tokens（输入）

3. 创建 API Key¶

访问密钥管理页面 1. 在灵积平台首页，点击右上角头像 2. 选择"API-KEY管理" 3. 或直接访问：https://dashscope.console.aliyun.com/apiKey

创建新的API Key 1. 点击"创建新的API-KEY"按钮 2. 系统会自动生成一个API Key 3. 重要：立即复制并保存API Key - API Key格式：sk-xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx - 只显示一次，关闭后无法再次查看 - 建议保存到安全的地方

API Key 管理 - 可以创建多个API Key用于不同项目 - 可以随时禁用或删除不需要的Key - 定期更换API Key提高安全性

4. 配置到 Horizon Arm¶

方法一：通过软件界面配置 1. 打开 Horizon Arm 软件 2. 切换到"具身智能"标签页 3. 在"LLM提供商"下拉框中选择"alibaba" 4. 在"API密钥"输入框中粘贴您的API Key 5. 选择模型（推荐：qwen-plus 或 qwen-turbo） 6. 点击"保存配置"

方法二：手动编辑配置文件 1. 找到软件安装目录下的配置文件： config/aisdk_config.yaml

  1. 使用文本编辑器打开，找到以下部分： yaml providers: alibaba: api_key: YOUR_API_KEY_HERE # 替换为您的API Key enabled: true default_params: max_tokens: 2000 temperature: 0.7 top_p: 0.8

  2. 将 YOUR_API_KEY_HERE 替换为您的API Key

  3. 保存文件并重启软件

5. 测试连接¶

验证配置 1. 在"具身智能"标签页 2. 在指令输入框中输入简单测试指令： 机械臂回到零位 3. 点击"执行指令" 4. 如果配置正确，系统会正常响应并执行

常见问题 - "API密钥无效"错误： - 检查API Key是否完整复制 - 确认API Key是否已启用 - 检查是否有网络连接

  • "配额不足"错误：
  • 检查账户余额
  • 查看免费额度是否用完
  • 考虑充值或购买资源包

DeepSeek 深度求索 API 获取教程¶

1. 注册 DeepSeek 账号¶

访问官网 - 打开浏览器，访问：https://platform.deepseek.com - 点击右上角"Sign up"（注册）按钮

注册流程 1. 选择注册方式： - 手机号注册 - 邮箱注册（推荐国际邮箱如Gmail） - Google账号快捷登录 - GitHub账号快捷登录

  1. 填写注册信息：
  2. 输入手机号或邮箱
  3. 设置密码（至少8位）
  4. 完成人机验证

  5. 输入验证码

  6. 完成注册：

  7. 点击注册按钮
  8. 验证邮箱/手机（如需要）

💡 提示：DeepSeek注册相对简单，不需要实名认证即可使用基础功能。

2. 充值与套餐选择¶

进入账户管理 1. 登录后，点击右上角头像 2. 选择"账户管理"或"Billing" 3. 查看当前余额和用量

充值方式 1. 点击"充值"或"Recharge"按钮 2. 选择充值金额： - 最低充值金额：通常为$5或更低 - 支持支付宝、微信支付、银行卡等

  1. 完成支付流程

💰 费用参考： - 新用户可能有免费额度（具体以官网为准） - DeepSeek-Chat: ¥0.001元/千tokens（输入） - DeepSeek-Chat: ¥0.002元/千tokens（输出） - 相比其他平台，DeepSeek价格较为实惠

免费额度说明 - 新用户注册后通常会获得一定的免费额度 - 免费额度有效期通常为30天 - 额度用完后需要充值才能继续使用

3. 创建 API Key¶

访问API密钥管理 1. 登录DeepSeek平台 2. 点击左侧菜单"API Keys" 3. 或直接访问：https://platform.deepseek.com/api_keys

创建新的API Key 1. 点击"Create API Key"按钮 2. 填写API Key信息： - Name：为API Key命名（例如：Horizon_Arm） - Description（可选）：描述用途

  1. 点击"Create"创建

  2. 重要：立即复制API Key

  3. API Key格式：sk-xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
  4. 只显示一次，关闭后无法查看
  5. 点击复制按钮保存到安全位置

API Key 安全管理 - 不要将API Key分享给他人 - 不要在公开代码库中暴露API Key - 可以创建多个Key用于不同项目 - 发现泄露立即删除并创建新的Key

4. 配置到 Horizon Arm¶

方法一：通过软件界面配置 1. 打开 Horizon Arm 软件 2. 切换到"具身智能"标签页 3. 在"LLM提供商"下拉框中选择"deepseek" 4. 在"API密钥"输入框中粘贴您的API Key 5. 选择模型： - deepseek-chat（推荐，性能优异） - deepseek-coder（代码专用） 6. 点击"保存配置"

方法二：手动编辑配置文件 1. 找到软件安装目录下的配置文件： config/aisdk_config.yaml

  1. 使用文本编辑器打开，找到以下部分： yaml providers: deepseek: api_key: YOUR_API_KEY_HERE # 替换为您的API Key enabled: true default_params: max_tokens: 2000 temperature: 0.7 top_p: 1.0

  2. 将 YOUR_API_KEY_HERE 替换为您的API Key

  3. 保存文件并重启软件

5. 测试连接¶

验证配置 1. 在"具身智能"标签页 2. 确认已选择"deepseek"提供商 3. 输入测试指令： 机械臂移动到初始位置 4. 点击"执行指令" 5. 观察系统响应和机械臂动作

性能优化建议 - temperature：控制创造性 - 0.3-0.5：精确控制，适合机械臂 - 0.7-0.9：更有创造性的对话

  • max_tokens：限制回复长度
  • 简单指令：500-1000
  • 复杂任务：1500-2000

常见问题 - "API key is invalid"错误： - 检查API Key是否正确完整 - 确认API Key是否已启用 - 尝试重新创建API Key

  • "Insufficient balance"错误：
  • 检查账户余额

  • 及时充值

  • 响应速度慢：

  • 检查网络连接
  • 减少max_tokens参数
  • 尝试切换网络环境

参数配置详解¶

配置文件位置¶

Horizon_Arm安装目录/
  └── config/
      └── aisdk_config.yaml

完整配置示例¶

# AI SDK 配置文件
providers:
  # 阿里云通义千问配置
  alibaba:
    api_key: sk-xxxxxxxxxxxxxxxxxxxxxxxxxx  # 您的API Key
    enabled: true                            # 是否启用
    description: 阿里云通义千问
    default_params:
      max_tokens: 2000      # 最大生成token数
      temperature: 0.7      # 温度参数(0-2)，越低越确定
      top_p: 0.8           # 核采样参数(0-1)

  # DeepSeek配置
  deepseek:
    api_key: sk-xxxxxxxxxxxxxxxxxxxxxxxxxx  # 您的API Key
    enabled: true                            # 是否启用
    description: DeepSeek深度求索
    default_params:
      max_tokens: 2000      # 最大生成token数
      temperature: 0.7      # 温度参数(0-2)
      top_p: 1.0           # 核采样参数(0-1)

# 日志配置
logging:
  level: INFO              # 日志级别：DEBUG/INFO/WARNING/ERROR
  file: AI_SDK.log        # 日志文件名
  max_size: 10485760      # 最大日志文件大小(10MB)
  backup_count: 5         # 保留的日志备份数量

# 会话配置
session:
  default_max_history: 20  # 默认最大历史记录数
  max_sessions: 100       # 最大会话数
  auto_cleanup: true      # 自动清理过期会话
  cleanup_interval: 3600  # 清理间隔(秒)

# 请求配置
request:
  timeout: 60            # 请求超时时间(秒)
  max_retries: 3         # 最大重试次数
  retry_delay: 1.0       # 重试延迟(秒)

# 缓存配置
cache:
  enabled: false         # 是否启用缓存
  type: memory          # 缓存类型：memory/redis
  ttl: 300              # 缓存过期时间(秒)
  max_size: 1000        # 最大缓存条目数

# 开发模式配置
development:
  debug: false           # 是否开启调试模式
  log_requests: false    # 是否记录所有请求
  mock_responses: false  # 是否使用模拟响应

# 安全配置
security:
  api_key_encryption: false  # API密钥是否加密存储
  rate_limiting:
    enabled: false       # 是否启用速率限制
    requests_per_minute: 60  # 每分钟最大请求数

参数说明¶

temperature（温度）¶

  • 范围：0.0 - 2.0
  • 说明：控制生成内容的随机性
  • 推荐值：
  • 0.3：精确控制，适合机械臂指令
  • 0.7：平衡创造性和准确性
  • 1.0+：更有创造性，适合对话

max_tokens（最大令牌数）¶

  • 范围：1 - 6000（根据模型不同）
  • 说明：限制生成内容的长度
  • 推荐值：
  • 500：简单指令
  • 1500：一般任务
  • 2000：复杂任务

top_p（核采样）¶

  • 范围：0.0 - 1.0
  • 说明：控制采样的多样性
  • 推荐值：
  • 0.8-0.9：平衡多样性和质量
  • 1.0：最大多样性

使用技巧与最佳实践¶

1. 选择合适的提供商¶

阿里云通义千问 - ✅ 优势： - 国内访问速度快 - 中文理解能力强 - 官方支持完善 - 稳定性好

  • 适用场景：
  • 需要快速响应
  • 中文指令为主
  • 对稳定性要求高

DeepSeek - ✅ 优势： - 价格实惠 - 推理能力强 - 代码理解优秀 - 性价比高

  • 适用场景：
  • 成本敏感用户
  • 复杂任务推理
  • 开发测试阶段

2. API 密钥安全¶

保护您的API Key - ❌ 不要硬编码在代码中 - ❌ 不要提交到Git仓库 - ❌ 不要分享给不信任的人 - ✅ 使用配置文件存储 - ✅ 定期更换密钥 - ✅ 监控使用情况

监控用量和费用 - 定期查看API调用统计 - 设置费用预警 - 避免意外超额消费

3. 成本优化¶

降低使用成本 1. 选择合适的模型： - 简单任务用轻量模型 - 复杂任务用高级模型

  1. 优化参数设置：
  2. 减少max_tokens
  3. 使用较低的temperature

  4. 精简prompt内容

  5. 合理使用功能：

  6. 避免频繁重复调用
  7. 批量处理任务
  8. 使用缓存功能

4. 性能优化¶

提高响应速度 1. 网络优化： - 使用稳定的网络连接 - 考虑使用国内节点（阿里云）

  1. 参数优化：
  2. 减少max_tokens
  3. 简化提示词

  4. 关闭不必要的功能

  5. 并发控制：

  6. 避免同时多个请求
  7. 合理设置超时时间

故障排除¶

连接问题¶

问题：无法连接到API服务 - 检查网络连接是否正常 - 确认API服务是否可访问 - 检查防火墙设置 - 尝试使用VPN（如需要）

问题：请求超时 - 增加timeout参数值 - 检查网络延迟 - 减少max_tokens - 尝试重启软件

认证问题¶

问题：API Key无效

错误信息：Invalid API key
  • 检查API Key是否正确完整
  • 确认API Key是否已激活
  • 尝试重新生成API Key
  • 检查API Key权限设置

问题：权限不足

错误信息：Permission denied
  • 检查API Key权限设置
  • 确认账户状态正常
  • 联系平台客服处理

配额问题¶

问题：配额不足

错误信息：Quota exceeded / Insufficient balance
  • 检查账户余额
  • 查看API调用配额
  • 充值或购买资源包
  • 等待配额重置（按量计费）

问题：速率限制

错误信息：Rate limit exceeded
  • 降低请求频率
  • 增加请求间隔
  • 升级付费套餐
  • 使用批量处理

配置问题¶

问题：配置文件格式错误 - 检查YAML语法是否正确 - 确认缩进使用空格（不是Tab） - 验证引号匹配 - 使用在线YAML验证工具

问题：配置不生效 - 确认配置文件路径正确 - 重启Horizon Arm软件 - 检查配置文件权限 - 查看日志文件获取详细信息

功能问题¶

问题：指令无法执行 - 检查机械臂连接状态 - 验证指令格式是否正确 - 查看具身智能日志 - 尝试简单的测试指令

问题：响应内容异常 - 调整temperature参数 - 优化提示词内容 - 检查模型选择是否正确 - 查看完整的错误日志
