Horizon_Arm 用户指南¶

使用用已安装的程序（exe）完成连接、控制与标定。

注：图片可右键放大查看；任何界面按空格键触发"全局急停"。

使用建议¶

  • ❓ 遇到问题：优先查看 故障排除
  • 📚 完整学习：按顺序阅读本指南章节
  • 🔍 快速查找：使用 Ctrl+F 搜索关键词

⚠️ 重要提示：首次使用前，请务必查看"电机参数设置"中的"6轴运动方向参考标准"，确保各轴运动方向与仿真系统一致。如发现方向不对，请及时调整电机方向参数。

⚠️ 重要安全注意事项¶

机械臂断电操作规范¶

禁止操作：

机械臂在通电运行状态下，严禁直接拔掉基座后面的电源线。工作环境应保持整洁，避免因拉扯、拖拽导致电源线意外脱落。

非正常断电的严重后果：

  1. 机械臂末端砸落
    瞬间断电会导致机械臂失去动力支撑，末端会因重力快速下坠，极易砸坏相机、夹爪等精密模块。

  2. 回零参数异常
    瞬时断电可能导致机械臂回零参数丢失或错乱，重新通电后回零位置可能偏离标准位置，影响后续操作精度。

  3. 电源系统故障
    非正常断电可能导致各轴电机的供电逻辑异常，电机会错误地将内部电池识别为主要电源，即使重新通电，机械臂仍处于失能状态。此时需要手动拆开各轴外壳，逐个重新插拔电池才能恢复正常。

正确断电流程：

  1. 扶住机身：断电前用手扶住机械臂，防止失能后砸落
  2. 手动关闭开关：在基座后面手动关闭电源开关
  3. 确认断电：等待指示灯熄灭，确认完全断电

💡 温馨提示：
养成良好的断电习惯，可以有效延长机械臂使用寿命，避免不必要的维修成本。

售后说明：

因人为操作不当（如非正常断电、暴力操作等）导致的机械臂末端夹爪、相机或机械臂整体部件损坏，不受理退货，仅支持自费维修。

如果出现通电机械臂无法直立，查看第四周电机后盖指示灯-绿-常亮，此时就要重新插拔电池，那几轴有问题就重新插拔那几轴的电池，具体电机电池位置参考图。

1. 许可证与激活¶

首次激活¶

激活步骤

  1. 启动程序：双击桌面"Horizon_Arm"图标，弹出激活窗口

  2. 输入信息：

    • 序列号：你收到的唯一序列号
    • 用户标识：手机号或邮箱

  3. 点击激活：点击"立即激活"按钮

  4. 激活成功：显示"激活成功"后关闭窗口

（首次激活将在打开软件时进行，如选择关闭激活窗口以及选择不激活将无法正常使用本软件）

首次激活演示

激活状态¶

状态类型

  • 已激活：显示"已激活（本机）"，无需再次操作

  • 未激活：显示"未激活，请输入序列号"，按上述步骤激活

  • 设备超限：显示"设备数量已达上限"，联系管理员处理

  • 已锁定（销毁）：显示"序列号已锁定（已销毁）"，该序列号已永久失效

激活状态查看

离线使用¶

使用说明 - 首次激活成功后，系统会在本机保存激活凭据 - 之后即使没有网络也可以正常启动和使用 - 序列号具有唯一性，不可复制或多设备共享

销毁锁定说明¶

含义 - 销毁锁定为不可逆操作，被执行后序列号永久禁用

锁定后影响 - 本机离线凭据在后续启动校验时失效 - 任意设备均无法再激活该序列号

注意 - 如需迁移/交接许可证，请先联系管理员合规处理，避免误销毁

**注意**：激活需要网络连接，激活成功后可离线使用

2. 开始之前¶

准备工作¶

版本区分

  • 驱动板绿灯常亮的是 X 版

  • 驱动板绿灯每间隔1秒闪烁的是 Y 版

  • 两版在同步、回零、到位确认等细节略有不同

本系统默认使用Y版

系统要求

  • 电脑：Windows 10/11（64 位）

  • 设备：USB 转 CAN（如 CANable，SLCAN 协议）

接线要求 - 确保 CAN_H/CAN_L 正确连接 - 电机上电且 ID 唯一（1~255）

4.1 连接步骤¶

1. 打开菜单"连接 → 连接电机"

2. 在弹出的对话框中设置

  • 串口：选择实际端口，如 COM8
  • 波特率：保持 500000（与驱动板配置一致）
  • 电机 ID：
  • 可点"单电机(ID=1) / 双电机(1,2) / 机械臂(1..6)"快速填入
  • 或在"自定义ID"里输入，如 1,2,3,4,5,6

3. 点击"确定"

  • 系统将逐一连接每个 ID
  • 并验证能否读取状态

4. 成功后确认

  • 状态栏显示"已连接 X 个电机"
  • 所有控制功能页面自动激活，可开始控制

7. 电机参数设置¶

6轴运动方向参考标准¶

在调整电机参数之前，请先了解各轴的标准运动方向。以下是基于仿真系统的6轴机械臂标准运动方向，所有方向描述均以机械臂自身为参考坐标系：

1轴（基座旋转）- 正方向参考

1轴正方向：基座逆时针旋转（以机械臂自身坐标系为准）

2轴（大臂摆动）- 正方向参考

2轴正方向：大臂向下摆动（以机械臂自身坐标系为准）

3轴（小臂摆动）- 正方向参考

3轴正方向：小臂向下摆动（以机械臂自身坐标系为准）

4轴（腕部旋转）- 正方向参考

4轴正方向：腕部右转（以机械臂自身方向为准）

5轴（腕部俯仰）- 正方向参考

5轴正方向：腕部向下俯仰（以机械臂自身坐标系为准）

6轴（末端旋转）- 正方向参考

6轴正方向：末端右转（以机械臂自身方向为准）

重要提示：如果您的机械臂某个轴的运动方向与上述参考方向相反，请按照下面的参数配置方法进行调整。

参数配置¶

访问方式 - 菜单：工具 → 电机参数设置

电机参数设置界面

默认参数配置¶

减速比设置¶

各关节电机的默认减速比配置：

电机ID 关节名称 默认减速比 说明
1 基座旋转 62.0 基座关节，需要较高精度
2 大臂摆动 51.0 大臂关节，承载较大负载
3 小臂摆动 51.0 小臂关节，平衡精度与速度
4 腕部旋转 62.0 腕部关节，需要较高精度
5 腕部俯仰 12.0 腕部俯仰，需要较快响应
6 末端旋转 10.0 末端关节，需要快速调整

方向设置¶

各关节电机的默认方向配置：

电机ID 关节名称 默认方向 数值 说明
1 基座旋转 反向 -1 逆时针为正方向
2 大臂摆动 反向 -1 向下摆动为正方向
3 小臂摆动 正向 1 向下摆动为正方向
4 腕部旋转 反向 -1 右转为正方向
5 腕部俯仰 正向 1 向下俯仰为正方向
6 末端旋转 反向 -1 右转为正方向

参数调整¶

减速比调整原则¶

  • 高精度关节：基座、腕部旋转使用较高减速比（62.0）
  • 负载关节：大臂、小臂使用中等减速比（51.0）
  • 快速响应关节：腕部俯仰、末端旋转使用较低减速比（10.0-12.0）

方向调整方法¶

步骤1：测试当前方向

  1. 打开"单电机控制"页面
  2. 选择要测试的电机ID（1-6）
  3. 使能电机
  4. 设置小角度（如10°）进行正方向测试
  5. 观察实际运动方向

步骤2：对比参考标准

  • 将实际运动方向与上述6轴方向参考GIF对比
  • 确认是否与标准正方向一致

步骤3：调整方向参数

如果运动方向与参考标准相反：

  1. 进入"电机参数设置"
  2. 找到对应电机的方向设置
  3. 将方向从"正向"改为"反向"，或从"反向"改为"正向"
  4. 点击保存设置

步骤4：验证调整结果

  1. 返回"单电机控制"页面
  2. 点击"重新加载配置"
  3. 重新测试该轴的正方向运动
  4. 确认运动方向与参考标准一致

方向调整对照表

轴号 参考正方向 如果实际相反 调整方法
1轴 基座逆时针旋转 基座顺时针旋转 正向↔反向切换
2轴 大臂向下摆动 大臂向上摆动 正向↔反向切换
3轴 小臂向下摆动 小臂向上摆动 正向↔反向切换
4轴 腕部右转（机械臂自身方向） 腕部左转 正向↔反向切换
5轴 腕部向下俯仰 腕部向上俯仰 正向↔反向切换
6轴 末端右转（机械臂自身方向） 末端左转 正向↔反向切换

坐标系说明：所有方向判断均以机械臂自身坐标系为准，向上就是向上，向下就是向下，不受观察角度影响。

旋转方向说明： - 左转/右转：站在机械臂前方观察，左转就是向左旋转，右转就是向右旋转 - 机械臂自身方向：以机械臂本身的坐标系为准，不受观察者位置影响 - 这样的描述比"顺时针/逆时针"更直观易懂

参数保存¶

自动保存 - 参数修改后会自动保存到系统中 - 下次启动程序时会自动加载之前的设置

参数保存

应用范围¶

自动应用模块 - 保存后自动应用到相关页面： - 单电机控制 - 机械臂控制
- 示教器 - 具身智能 - 视觉抓取 - 其他相关功能模块

应用新参数 - 修改参数后，需要在相关功能页面点击"重新加载配置" - 或重启程序使新参数生效

使用建议¶

调试流程

  1. 逐个测试：逐个关节测试运动方向和速度

  2. 小幅调整：每次只调整一个参数，观察效果

  3. 验证效果：确认调整后的参数符合预期

14. IO控制系统¶

核心功能¶

IO控制系统是Horizon具身智能机械臂的外部信号交互模块，通过ESP32微控制器实现数字输入(DI)和数字输出(DO)的控制，支持外部设备触发机械臂作业执行和机械臂状态输出。

主要特性

  • 外部信号触发：通过DI信号自动触发预设作业

  • 设备联动控制：通过DO信号控制外部设备

  • 生产线集成：支持与生产线设备的信号交互

  • ESP32微控制器：稳定可靠的硬件控制平台

硬件配置¶

数字输入(DI)

  • 8路数字输入：DI0-DI7

  • GPIO引脚：23, 22, 17, 16, 21, 19, 18, 5

  • 支持上升沿、下降沿、高电平、低电平触发

  • 内部上拉电阻配置

数字输出(DO)

  • 8路数字输出：DO0-DO7

  • GPIO引脚：2, 4, 25, 26, 27, 32, 33, 13

  • 3.3V输出电平

  • 支持手动控制和程序控制

使用流程¶

1. 连接ESP32

  • 选择正确的串口（波特率115200）

  • 点击"连接"按钮建立通信

2. 配置IO映射

  • 添加DI映射：设置触发方式和关联作业

  • 添加DO映射：配置输出控制

  • 保存配置文件

3. 创建作业

  • 创建普通作业或导入示教程序

  • 添加关节运动、夹爪控制、等待、IO控制等步骤

  • 保存作业到配置文件

4. 外部控制模式

  • 进入外部控制模式

  • 系统监控DI状态变化

  • 自动执行对应作业

应用场景¶

Horizon ARM 1.3版本配备了完整的全局紧急停止系统，确保在任何情况下都能快速停止所有运动。

18. 多电机控制¶

同步控制¶

面向同步/批量操作。窗口包含"同步控制 / 批量操作 / 循环控制 / 回零参数设置 / 状态监控"等标签。

常用场景

同步控制 - 为多台电机设置目标（直通/梯形/速度等） - 发送带同步标志命令 - 系统自动处理同步触发信号

批量操作 - 批量使能/失能 - 批量停止

循环控制 - 配置每台电机的动作序列，循环执行

状态监控 - 周期读取各电机状态，显示是否在线、当前角度/速度等

同步控制说明¶

同步原理 - X版：同步标志 + 广播触发模式 - Y版：多电机命令一次性下发模式 - 确保多电机协调运动

同步设置步骤

  1. 连接电机：确保所有目标电机已正确连接

  2. 使能电机：批量使能所有参与同步的电机

  3. 设置目标：为每台电机设置运动目标参数

  4. 发送同步命令：系统自动处理同步标志和触发

  5. 监控执行：观察所有电机的同步运动状态

状态监控参数 - 刷新频率：默认100ms - 监控内容：位置、速度、温度、电压、电流 - 在线状态：实时显示电机连接状态 - 到位状态：显示电机是否到达目标位置

使用技巧¶

同步控制建议

  1. 预备工作：同步前确认所有电机已使能

  2. 参数检查：确保各电机参数设置合理

  3. 逐步测试：先进行小幅度同步测试

  4. 监控状态：实时观察电机状态和响应

故障排除

  • 同步失败：检查电机ID是否唯一

  • 运动不协调：检查各电机的减速比和方向设置

  • 通信异常：检查CAN总线连接和波特率设置

小贴士 - 同步前确认所有电机已使能，且已成功读取过状态 - 同步失败时，优先检查 ID 是否唯一、是否设置了同步标志以及是否发送了广播触发 - 建议在同步控制前先用单电机控制验证各电机工作正常

20. 常见问题与排查¶

连接失败/无响应¶

检查项目 - 是否选对串口（设备管理器确认）？ - 波特率 500000、CAN 速率 500K 是否匹配？ - 电机是否上电、ID 唯一？ - 是否被其他程序占用串口（如 CANgaroo）？

多机同步不工作¶

检查项目 - 是否对每台电机发送了"带同步标志"的命令？ - 是否发送了广播同步触发（ID=0，00 FF 66 6B）？ - 所有电机是否都已使能且能读取状态？

状态读取不稳定¶

解决方法 - 检查 USB 线缆与接口 - 仅保留本程序占用 CAN/串口 - 降低读取频率（状态监控标签中调整）

位置角度异常/方向不一致¶

解决方法 - 在"电机参数设置"里校正减速比与方向 - 小范围、低速度试动，确认后再进行大幅度动作

数字孪生显示异常¶

解决方法 - 检查显卡/驱动兼容性 - 尝试更新或更换电脑
